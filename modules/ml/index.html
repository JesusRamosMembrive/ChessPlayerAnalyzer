    1. model.py - Arquitectura del Modelo

    Definición de arquitectura neural simple para clasificación binaria.

    Arquitectura

    def build_model(_args=None):
    """
    Red neuronal feedforward simple.

    Arquitectura:
    - Input: 128 features
    - Hidden: 64 neurons (ReLU)
    - Output: 2 classes (binary classification)

    Casos de uso:
    - Clasificación de calidad de movimientos
    - Detección de patrones de juego
    - Análisis de comportamiento de jugador
    """
    return nn.Sequential(
        nn.Linear(128, 64),  # Feature extraction
        nn.ReLU(),           # Non-linearity
        nn.Linear(64, 2),    # Binary classification
    )

    Especificaciones Técnicas

    • Input dim: 128 (vectores de características de chess)
    • Hidden layers: 1 capa de 64 neuronas
    • Output: 2 logits para clasificación binaria
    • Activation: ReLU para capa oculta
    • Parameters: ~8,450 parámetros totales
    • Memory: ~33KB en memoria

    """
    Genera datasets sintéticos para desarrollo.

    Características:
    - 1024 samples sintéticas

    - Labels: 2 clases balanceadas

    • Split: Mismo dataset para train/validation (desarrollo)

    Función de Validación

    def validate(model, loader, device):
    """
    Evaluación del modelo en validation set.

    Returns:
    - accuracy: Precisión como float [0, 1]
    """
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for xb, yb in loader:
            logits = model(xb.to(device))
            pred = logits.argmax(dim=1)
            correct += (pred == yb.to(device)).sum().item()
            total += yb.size(0)
    return correct / max(1, total)

    Argumentos de CLI

    python -m app.ml.train \
    --epochs 5 \                    # Número de epochs
    --lr 1e-3 \                     # Learning rate
    --batch-size 64 \               # Batch size
    --use-cuda \                    # Habilitar CUDA
    --output /app/model_store/model.pt  # Path del modelo

    Proceso de Checkpointing

    • Best model saving: Solo guarda el modelo con mejor accuracy
    • CPU state_dict: Convierte a CPU antes de guardar
    • Path fijo: /app/model_store/model.pt (mounted volume)
    • Fallback: Guarda último modelo si ninguno mejora baseline

    4. inference.py - Sistema de Inferencia

    Sistema de inferencia con cache global y lazy loading.

    Global Model Cache

    _model = None  # Global singleton

def get_model(device="cpu", weights_path="/app/model_store/model.pt"):
    """
    Lazy loading con cache global.

    Características:
    - Singleton pattern para eficiencia
    - Lazy loading en primera llamada
    - Cache persistent durante vida del worker
    - Device-agnostic loading
    """
    global _model
    if _model is None:
        m = build_model({})
        state = torch.load(weights_path, map_location=device)
        m.load_state_dict(state)
        m.eval()
        _model = m.to(device)
    return _model

    Optimizaciones

    • Singleton: Un solo modelo cargado por worker
    • map_location: Carga en device correcto automáticamente
    • eval() mode: Modelo en modo inferencia (sin gradientes)
    • Persistent cache: Modelo vive durante toda la sesión del worker

    5. ml_tasks.py - Celery ML Tasks

    Tareas de Celery especializadas para inferencia ML con cola dedicada.

    Tarea de Inferencia

    @celery_app.task(name="app.ml_tasks.infer_model", queue="torch")
def infer_model(vector):
    """
    Inferencia ML via Celery con cola torch dedicada.

    Args:
        vector: List[float] - Vector de 128 features

    Returns:
        {"probs": [float, float]} - Probabilidades softmax
    """
    device = "cuda" if torch.cuda.is_available() else "cpu"
    model = get_model(device=device)

    # Tensor processing
    x = torch.tensor(vector, dtype=torch.float32, device=device).view(1, -1)

    with torch.no_grad():
        logits = model(x)
        probs = logits.softmax(dim=1).cpu().numpy().tolist()[0]

    return {"probs": probs}

    Características de la Tarea

    • Queue dedicada: queue="torch" para isolation
    • Device detection: CUDA/CPU automático
    • Input validation: Tensor conversion con error handling
    • Output format: Probabilidades normalizadas [0, 1]
    • Memory efficient: torch.no_grad() context
    • CPU return: Resultado siempre en CPU para serialización

@celery_app.task(bind=True)
def infer_model(self, vector):
    try:
        if len(vector) != 128:
