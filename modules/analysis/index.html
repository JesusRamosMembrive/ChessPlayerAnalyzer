    Módulos de Análisis - ChessPlayerAnalyzer

    Audiencia: Data Scientists, Desarrolladores Última actualización: 2025-09-13 Estado: Completo

    Documentación completa de los módulos de análisis especializados que calculan métricas avanzadas de partidas y jugadores de ajedrez.

    <¯ Objetivo

    Los módulos de análisis proporcionan: - Métricas de calidad - Evaluación de precisión y fuerza de juego - Análisis temporal - Patrones de tiempo y manejo del reloj - Evaluación de aperturas - Repertorio, preparación y novedad - Análisis de endgame - Eficiencia con tablebases Syzygy - Detección de anomalías - Patrones sospechosos y clasificación - Análisis longitudinal - Tendencias y evolución temporal - Machine Learning - Clasificación y clustering

    =Ê Módulos Core

    1. quality.py - Métricas de Calidad

    Evaluación de la precisión y fuerza de juego.

    Métricas principales: - ACPL (Average Centipawn Loss) - Pérdida promedio de centipawns - IPR (Intrinsic Performance Rating) - Rating intrínseco basado en posiciones - Match Rate - % de coincidencia con las mejores jugadas del motor - WDL Loss - Pérdida de probabilidad Win/Draw/Loss - Precision Bursts - Rachas de jugadas casi perfectas

    Funciones clave: 

    def acpl(game_df, player_color='white', cap_cp=1500, use_median=True) -> float:
    """Calcula ACPL usando media o mediana (más robusta)"""

def match_rate(game_df, engine_depth=15, top_n=3) -> float:
    """% de jugadas que coinciden con top-N del motor"""

def weighted_match_rate(game_df, complexity_weights=True) -> float:
    """Match rate ponderado por complejidad de posición"""

def intrinsic_performance_rating(game_df, reference_ratings) -> float:
    """IPR basado en estadísticas por nivel ELO"""

    Ejemplo de uso: 

    from app.analysis.quality import aggregate_quality_features

# Analizar partida completa
quality_metrics = aggregate_quality_features(game_df)
# {
#   'acpl': 23.5,
#   'match_rate': 0.87,
#   'ipr': 2156,
#   'precision_burst_count': 3
# }

    2. timing.py - Análisis Temporal

    Patrones de tiempo y manejo del reloj.

    Métricas principales: - Time Variance - Variabilidad en el tiempo por movimiento - Time-Complexity Correlation - Correlación entre tiempo y dificultad - Lag Spikes - Picos anómalos de tiempo - Uniformity Score - Consistencia temporal (0-1) - Clutch Accuracy - Precisión bajo presión temporal

    Funciones clave: 

    def time_stats(game_df) -> Tuple[float, float, float]:
    """Media, std, coef. variación de tiempos"""

def time_complexity_corr(game_df, complexity_col='legal_moves') -> float:
    """Correlación Spearman tiempo vs complejidad"""

def lag_spikes_detection(game_df, multiplier=5.0) -> List[int]:
    """Detecta movimientos con tiempo > multiplier * media"""

def uniformity_score(game_df, method='coefficient_variation') -> float:
    """Score 0-1 de uniformidad temporal"""

    3. openings.py - Análisis de Aperturas

    Evaluación de repertorio y preparación.

    Métricas principales: - Opening Entropy - Diversidad del repertorio (bits) - Novelty Depth - Profundidad de salida del libro teórico - Second Choice Rate - Frecuencia de segundas mejores jugadas - Opening Breadth - Número de sistemas diferentes jugados - Preparation Depth - Profundidad media de preparación

    Funciones clave: 

    def shannon_entropy(series) -> float:
    """H = £ p_i·log2(p_i) en bits"""

def novelty_ply(game, book) -> int:
    """Ply donde se desvía del libro teórico"""

def second_choice_frequency(game_df) -> float:
    """% de jugadas que son 2ª mejor según motor"""

def opening_preparation_metrics(games_list) -> Dict:
    """Análisis agregado de preparación"""

    4. endgame.py - Análisis de Endgame

    Evaluación con tablebases Syzygy (si están disponibles).

    Métricas principales: - TB Match Rate - % coincidencia con tablebases - DTZ Deviation - Desviación de Distance-to-Zero óptimo - Conversion Efficiency - Movimientos para convertir ventaja - Endgame Accuracy - Precisión en finales teóricos

    Funciones clave: 

    def syzygy_tablebase_analysis(game_df, tb_path) -> Dict:
    """Análisis con tablebases Syzygy si disponible"""

def endgame_conversion_rate(game_df, advantage_threshold=200) -> float:
    """Tasa de conversión de ventajas"""

def theoretical_endgame_accuracy(game_df) -> float:
    """Precisión en finales con <7 piezas"""

    5. anomaly.py - Detección de Anomalías

    Identificación de patrones anómalos y sospechosos.

    Técnicas utilizadas: - Isolation Forest - Detección de outliers multivariante - Local Outlier Factor (LOF) - Anomalías basadas en densidad local - Statistical Process Control - Control estadístico de procesos - Z-Score Analysis - Detección de valores extremos

    Funciones principales: 

    def isolation_forest_anomaly_score(features_df) -> np.ndarray:
    """Scores de anomalía usando Isolation Forest"""

def statistical_outlier_detection(series, method='iqr') -> List[int]:
    """Detección de outliers por IQR o Z-score"""

def aggregate_anomaly_features(game_df) -> Dict:
    """Métricas agregadas de anomalía"""

    6. bayesian.py - Modelos Bayesianos

    Análisis probabilístico de comportamiento.

    Modelos implementados: - Bayesian Suspicion Model - Probabilidad de comportamiento anómalo - Performance Priors - Priors basados en rating y experiencia - Evidence Integration - Combinación de múltiples señales

    Clase principal: 

    class BayesianSuspicionModel:

    def update_evidence(self, evidence: Dict[str, float]) -> float:

    def compute_posterior(self) -> Tuple[float, Dict]:
        """Compute final posterior probability"""
