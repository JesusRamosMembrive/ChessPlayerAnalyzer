# Historical Suspicion Priors

This repository stores aggregated statistics of suspicious games by Elo and
experience in `data/suspicion_priors.json`. The file is generated by running:

```bash
python scripts/collect_suspicion_stats.py
```

For each rating bucket (width 200 Elo) and experience bucket (width 50 games)
we store the number of suspicious games and total games. These counts are
converted into Beta distribution parameters `(alpha, beta)` using a
Beta-Binomial model with a uniform prior (add-one smoothing).

The `BayesianSuspicionModel` loads these parameters to derive the prior
probability of a game being suspicious. As a player accumulates more
non-suspicious games, the prior shrinks accordingly.
