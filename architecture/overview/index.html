    Arquitectura General del Sistema

    Audiencia: Desarrolladores, Arquitectos Última actualización: 2025-09-13 Estado: Completo

    ChessPlayerAnalyzer es un sistema distribuido de análisis de ajedrez que combina análisis de motor (Stockfish), métricas estadísticas avanzadas y machine learning para evaluar partidas y jugadores de Chess.com.

    <¯ Objetivo

    Proporcionar análisis profundo y detallado de: - Partidas individuales - Calidad de jugadas, patrones temporales, aperturas - Jugadores - Métricas agregadas, detección de patrones, análisis longitudinal - Comportamiento - Identificación de anomalías y análisis de fairness

    >é Componentes Principales

    1. API FastAPI (app/main.py)

    • Puerto: 8000
    • Función: Punto de entrada REST para todas las operaciones
    • Características:
    • API versionada (/api/v1/)
    • Documentación automática OpenAPI
    • Middleware de rate limiting, logging y tracing
    • Manejo de estado de tareas asíncronas

    2. Workers Celery (app/celery_app.py)

    • Función: Procesamiento asíncrono de análisis
    • Configuración:
    • Cola default: Análisis estándar con Stockfish
    • Cola torch: Análisis ML con PyTorch
    • Prioridades: 0 (alta) a 9 (baja)
    • Timeouts: 30min soft / 31min hard

    3. Base de Datos PostgreSQL (app/models.py)

    • Esquema principal:
    • Game - Partidas PGN y metadatos
    • MoveAnalysis - Análisis por movimiento
    • GameAnalysisDetailed - Métricas avanzadas por partida
    • Player - Información de jugadores
    • PlayerAnalysisDetailed - Métricas agregadas

    4. Redis

    • Usos múltiples:
    • Message broker para Celery
    • Cache de resultados
    • Notificaciones WebSocket/SSE
    • Control de estado de procesos

    5. Motor de Análisis (app/analysis/)

    • Stockfish: Evaluación posicional y líneas principales
    • Módulos especializados:
    • quality.py - Calidad de jugadas (ACPL, IPR, match rate)
    • timing.py - Patrones temporales y uniformidad
    • openings.py - Análisis de repertorio y novelties
    • endgame.py - Evaluación con tablebases Syzygy
    • bayesian.py - Modelos probabilísticos
    • ml_classifier.py - Clasificación ML

    =à Tecnologías Clave

    Backend

    • FastAPI - Framework web asíncrono
    • SQLModel - ORM con tipos Pydantic
    • Celery - Queue de tareas distribuidas
    • PostgreSQL - Base de datos relacional
    • Redis - Cache y message broker

    Análisis

    • Stockfish - Motor de ajedrez UCI
    • python-chess - Manipulación de partidas
    • scikit-learn - Machine learning
    • statsmodels - Análisis estadístico
    • PyTorch - Deep learning (cola torch)

    Observabilidad

    • OpenTelemetry - Tracing distribuido
    • Jaeger - UI de trazas
    • Prometheus - Métricas (FastAPI Instrumentator)
    • JSON Logging - Logs estructurados

    Deployment

    • Docker - Containerización
    • Docker Compose - Orquestación local
    • Multi-stage builds - Optimización de imágenes

    =Ê Métricas y Análisis

    Niveles de Análisis

    1. Movimiento (MoveAnalysis)

    • Evaluación Stockfish (centipawns)
    • Ranking de jugada (1=mejor, 2=segunda mejor, etc.)
    • Pérdida de centipawns
    • Tiempo gastado

    2. Partida (GameAnalysisDetailed)

    • Calidad: ACPL, IPR, match rate, precisión
    • Temporal: Varianza tiempo, correlaciones, spikes
    • Apertura: Entropía, novelty depth, breadth
    • Endgame: Syzygy tablebase accuracy
    • Avanzado: Modelos bayesianos, clustering

    3. Jugador (PlayerAnalysisDetailed)

    • Agregaciones de métricas de partidas
    • Análisis longitudinal y tendencias
    • Risk score y clasificaciones
    • Comparaciones con cohortes

    = Consideraciones de Seguridad

    Rate Limiting

    • Middleware personalizado con Redis

    • Protección contra DoS

    Validación

    • Schemas Pydantic estrictos

    • Validación de usernames Chess.com

    Observabilidad
